# Getting help

Start with [setup and troubleshooting](docs/TROUBLESHOOTING.md). It covers first-launch approval, permissions, Right Option gestures, model loading, and text insertion.

If it still doesn't work, [open a bug report](https://github.com/dhirajcdry/justwisper/issues/new?template=bug_report.yml). Include:

- Mac model, macOS version, and app version.
- Selected speech model and microphone.
- Which app/text field you were dictating into.
- The exact key sequence, expected result, and observed result.
- A short sample or redacted diagnostic output, if useful.

Use fictional text in recordings and screenshots. Don't attach your history file or unreviewed logs. Older app versions logged transcript text; current builds record counts and timings instead of intentionally logging transcripts.

Feature ideas belong in [feature requests](https://github.com/dhirajcdry/justwisper/issues/new?template=feature_request.yml). Describe the problem you want to solve. The [roadmap](ROADMAP.md) lists current priorities without promising dates.

This is an independently maintained early-stage project. Responses and fixes are best-effort; there is no paid support service or guaranteed response time. For a security issue, follow [SECURITY.md](SECURITY.md).
